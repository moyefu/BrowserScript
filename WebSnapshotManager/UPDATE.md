## [1.4.3] - 2026-08-27

### ☁️ 自定义主题深度集成 GitHub Gist 云同步
- **自定义主题双向增量同步与合并**：
  - 云同步协议扩展支持 `custom_themes` 与主题墓碑（`theme_tombstones`），仅同步用户个性化新建与导入的自定义主题，官方内置预设保持纯净；
  - 增量合并引擎支持版本时间戳判断（`updatedAt` 择新）与 30 天墓碑清理机制，保证多设备间自定义主题增删改的精准同步；
- **主题操作全链路自动同步触发**：
  - 新建、修改、删除或导入自定义主题时，自动触发展期增量同步调度（`scheduleAutoSync`）；
  - 云同步完成后无缝刷新全局主题列表、顶栏快捷菜单并即时应用生效。

### 🎨 主题选项响应式截断控制与修改/新增自定义主题拆分
- **主题卡片文本长度截断与弹性自适应**：
  - 为主题网格单元与标题设置 `min-width: 0`、`text-overflow: ellipsis` 与 `flex-shrink: 0`，防止长文本撑开网格破坏布局；
  - 增强当前激活主题卡片（`theme-current-card`）标题与状态徽章的截断保护；
- **自适应单列自然换行（一行一个，无需维护多套样式）**：
  - 采用 `grid-template-columns: repeat(auto-fill, minmax(190px, 1fr))` 纯布局自适应，当窗口或可用宽度不足时自然换行为单列展示（一行一个），无需侵入修改移动端规则或做两套分支处理；
- **“自定义配色微调与新建”拆分为独立“修改”与“新增”**：
  - **✏️ 修改当前配色**：快速修改当前主题名称与 Accent / Paper / Header 配色，若为自定义主题直接持久化覆盖更新，若为官方预设则生成独立副本保存并应用；
  - **➕ 新建自定义主题**：基于当前主题为模板，快速创建全新自定义主题，赋予新主题独立唯一 ID 并即时生效；
  - 配套优化主题编辑器标题指示、表单预填充、按钮激活高亮以及「✕ 收起」快捷交互。

## [1.4.2] - 2026-08-27

### 🛡️ Trusted Types 策略引擎与严格 CSP 全环境深度兼容
- **多策略智能白名单适配 (`Trusted Types`)**：
  - 自动轮询创建与探测常见策略标识（`default`, `snapshotPolicy`, `webSnapshotManager`, `goog#html`, `dompurify`, `angular#unsafe-bypass`, `nextjs#html` 等），全面兼容 `window.trustedTypes` 与 `unsafeWindow.trustedTypes`；
- **安全渲染与多层降级引擎 (`setSafeInnerHTML`)**：
  - 实现了三级 DOM 安全注入降级方案（`innerHTML(TrustedHTML)` $\to$ `createContextualFragment` $\to$ `DOMParser` $\to$ `replaceChildren`），确保无论页面 CSP 策略多严苛均能 100% 成功渲染；
- **全局 `Element.prototype.innerHTML` 拦截器**：
  - 在 Userscript 上下文自动重写 `innerHTML` Setter，透明将原生 HTML 字符串转译为 `TrustedHTML`，防止第三方或内部调用直接触发拦截；
- **主界面显式安全注入**：
  - 针对 `initApp` 根节点、弹窗与各卡片渲染全面接入安全注入体系，彻底消除 `This document requires 'TrustedHTML' assignment` 报错。

## [1.4.0] - 2026-08-27

### 🎨 主题组合封装 JSON、自定义主题导入/导出与 Yohaku 初始默认配置
- **结构化 JSON 主题系统 (`ThemeEngine`)**：
  - 将所有界面样式与配色解耦封装为标准化 `LSM_THEME` JSON 格式（包含元数据、Tokens 字典、材质底色、边框、阴影、圆角及字体规范）；
  - **默认初始配置**：内置并将 **Yohaku (余白)** 作为默认初始化主题，同时提供 5 套精美官方预设（🌸 余白 / 🔷 经典科技蓝 / 🌑 曜石暗夜 / 🌸 春櫻粉紫 / 🍵 宇治抹茶）；
  - **动态 CSS 变量注入**：Shadow DOM 样式全面重构为 `--lsm-*` CSS 变量，切换主题 **0 延迟、0 闪烁、0 刷新** 实时热生效。
- **自定义主题导入 / 导出与流转**：
  - **📤 导出主题 (JSON)**：一键将当前主题打包导出为 `.json` 配置文件或直接复制格式化 JSON 到剪贴板；
  - **📥 导入主题 (JSON)**：支持选取本地 `.json` 主题文件或直接粘贴 JSON 字符串，自动校验 Schema、智能容错补全缺失字段并即时激活；
  - **✏️ 配色微调与新建**：内置可视化颜色选择器，支持实时微调 Accent、Paper、Header 等配色并保存为新的专属主题；
  - **🔄 一键恢复默认**：任何时候均可一键重置为 Yohaku (余白) 官方默认配置；
  - **内置删除防护**：官方预设受系统保护禁止误删，用户自定义主题支持一键删除与回退。
- **专属「🎨 主题风格设置」抽屉与扩展菜单联动**：
  - 工具栏下拉菜单与油猴/ScriptCat 扩展菜单新增 **「🎨 主题风格设置」** 快捷入口；
  - 抽屉内置当前主题色板预览（Color Swatches Palette）与多主题网格卡片选择器。

## [1.3.0] - 2026-08-27

### ☁️ GitHub Gist 云同步与三大核心数据同步策略升级
- **墓碑机制 (Tombstones) 彻底解决删除快照后被云端复活问题（问题 1）**：
  - 本地删除快照时自动生成带时间戳的墓碑标记（`LSM_TOMBSTONES`）；
  - 双向增量同步时自动合并两端墓碑列表，依据 `deletedAt >= updatedAt` 精准在云端与本地同步剔除已删除快照，杜绝旧快照被反向恢复；
  - 内置 30 天墓碑自动垃圾回收（GC）机制，防止元数据无限占用存储。
- **全自动双向互补增量合并（纯净无损同步）**：
  - 移除所有单向强制覆盖（强制推送/强制拉取），全面采用智能双向互补增量算法；
  - 本地与云端各自独有的快照自动双向合并互补，两端共有快照按 `updatedAt` 时间戳保留最新版本，双方数据 100% 完整保留不丢失。
- **全自动防抖与一键同步体系**：
  - **常规操作**：顶部状态栏实时指示云端连接状态（未配置/就绪/同步中/异常），工具栏新增 **【🔄 同步】** 快捷按钮（带旋转动效），支持一键双向增量同步；
  - **自动化控制**：新增 **【快照变更时自动同步】** 开关，在快照新增、改名、删除后执行 2 秒防抖自动同步；打开面板时若距离上次同步超过 5 分钟自动静默拉取。
- **专属「☁️ 云同步设置抽屉」与已有 Gist 实时搜索选择**：
  - 提供专属毛玻璃云同步配置抽屉，支持输入 GitHub Personal Access Token 并提供眼睛图标明密文切换；
  - 新增 **「📋 搜索/选择已有 Gist」** 交互弹窗：基于 GitHub API 获取账号下全部 Gist，支持描述/文件名/ID 实时模糊搜索，优先置顶推荐含有快照备份文件的 Gist，点击即一键绑定；
  - 提供 **「🚀 自动创建 Gist」** 功能，一键在 GitHub 上创建专属 Secret Gist 并自动绑定；
  - 提供 **「🔍 测试连接与权限」** 按钮，即时验证 Token 状态并展示用户名与 Gist 数量；
  - 隐藏设置抽屉内的滚动条，保持界面简洁现代，同时支持滚轮顺滑滑动。

## [1.2.1] - 2026-08-26

### 🧩 大体积快照分片轮播与乱序扫码聚合还原
- **超限分片二维码生成与 500ms 轮播播放器**：
  - 当快照体积超出标准单张二维码容纳上限（> 2.2 KB）时，智能判定并展示超限友好提示与 **「分片轮播生成」** 入口；

  - 播放器内置当前进度指示条、已播帧数/总分片数统计、播放/暂停开关与前后分片手动切换控制。
- **摄像头实时扫码与多片乱序暂存聚合**：
  - 扫码器支持实时接收并解析分片数据帧，自动暂存并持续保持摄像头开启；
  - 视窗上方动态呈现分片接收 HUD 进度条与实时点阵，支持任意次序、任意方向扫描；
  - 分片集齐后自动拼装校验并一键调起还原抽屉，无需手动干预。
